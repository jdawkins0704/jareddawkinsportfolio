MCU Explorer

An API-powered React application that makes the Marvel Cinematic Universe easier to search, filter, and explore.

Back to projects View live project

Overview

MCU Explorer is an interactive web application that helps users navigate Marvel Cinematic Universe titles without feeling overwhelmed by the size of the franchise. Users can search the catalog, filter titles by MCU phase, browse releases chronologically, view title details, and save favorites.

My role

  • Designed the application’s information architecture and navigation
  • Built the interface with React, HTML, and CSS
  • Integrated live movie data from the TMDB API
  • Created search, phase filtering, timeline, and favorites functionality
  • Deployed the frontend and secure serverless API through Vercel

Process & thinking

I approached MCU Explorer as both a product and technical problem. The MCU contains an expanding catalog of interconnected titles, so I organized the experience around the ways users naturally explore it: searching for a specific title, browsing by phase, following release order, and saving favorites.

When the original third-party MCU API became unavailable, I diagnosed the failure and rebuilt the data layer using TMDB. I routed requests through a Vercel serverless function, protected the access token with an environment variable, transformed the response into the structure expected by the interface, and cached results for faster loading.

Outcome

  • Live MCU information and poster artwork retrieved through TMDB
  • Searchable catalog organized across six MCU phases
  • Chronological timeline and persistent favorites
  • A responsive interface supporting desktop and mobile use
  • A secure API integration that keeps credentials out of the browser
